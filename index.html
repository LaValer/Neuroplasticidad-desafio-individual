Neuroplasticidad y aprendizaje: ¿cuántas semanas de práctica necesito?

Desafío individual · Métodos Numéricos · EDO de primer orden · Heun y Runge-Kutta 4
Estudiante: Mamani Cerezo Laura Valeria

1. Problema y contexto

Comunidad beneficiaria: estudiantes universitarios que quieren dominar un tema nuevo (por ejemplo, métodos numéricos). La neuroplasticidad es la capacidad del cerebro de fortalecer conexiones neuronales con la práctica repetida: al inicio se progresa rápido y, cerca del dominio total, cada vez más lento.

Pregunta: ¿cuántas semanas de práctica constante se necesitan para alcanzar la meta de dominio (por ejemplo 80 %), y qué tan bien la calculan los métodos de Heun y RK4?

Los parámetros son hipotéticos. Esta simulación ilustra un modelo y no es una predicción comprobada con datos reales.

2. Modelo matemático

Variable dependiente: y(t) = nivel de dominio del tema (% ). Variable independiente: t = tiempo (semanas).
Parámetros: M = dominio máximo (%), r = tasa de aprendizaje (1/semana), y₀ = dominio inicial (%).

dy/dt = r·(M − y),   y(0) = y₀

Justificación: la velocidad de aprendizaje es proporcional a lo que aún falta por aprender (M − y). Supuestos: práctica constante cada semana, r constante, el dominio nunca supera M.

Solución analítica (separación de variables: ∫dy/(M−y) = ∫r dt → −ln|M−y| = rt + C):

y(t) = M − (M − y₀)·e−r·t

Verificación: y(0) = M − (M − y₀) = y₀ ✔. Derivando: y′(t) = r·(M − y₀)·e−rt = r·(M − y(t)) ✔.
Tiempo para llegar a la meta Y*: t* = ln((M − y₀)/(M − Y*)) / r.

Heun (RK2): k₁ = f(yₙ); k₂ = f(yₙ + h·k₁); yₙ₊₁ = yₙ + (h/2)(k₁ + k₂).
RK4: k₁ = f(yₙ); k₂ = f(yₙ + h·k₁/2); k₃ = f(yₙ + h·k₂/2); k₄ = f(yₙ + h·k₃); yₙ₊₁ = yₙ + (h/6)(k₁ + 2k₂ + 2k₃ + k₄), con f(y) = r·(M − y).
